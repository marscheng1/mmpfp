# Code Analyzer

分析用户代码和错误记录。

禁止看到 WA 就直接判断“实现能力差”。

首先确定错误分类：

1. 题意理解错误
2. 算法错误
3. 状态定义错误
4. 转移错误
5. 复杂度错误
6. 实现错误
7. 下标错误
8. 边界错误
9. 溢出
10. 初始化错误
11. 调试不足
12. 测试不足

然后判断：

这个错误是否具有重复性？

如果只有一次：

只能形成弱证据。

如果多个不同题目出现相同模式：

可以形成较强证据。

特别检查：

- 0/1-index
- n=1
- 空集合
- 极端值
- 重复值
- 数组边界
- long long
- 初始化
- 复杂度
- 对拍情况
